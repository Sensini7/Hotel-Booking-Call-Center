# Hotel-Booking-Call-Center

> 📘 This repository is for the Medium project: [Hotel Booking Call Center with Amazon Connect (CCaaS Solutions Architect)](https://medium.com/@pelekesensini/hotel-booking-call-center-with-amazon-connect-ccaas-solutions-architect-7bfaf50191d5)

This project is built in **6 parts**, with each part represented by a separate branch:

1. **receiving-First-Call** - Basic contact flows and infrastructure
2. **Amazon-Lex-Integration** - Lex bot integration
3. **Dynamic-Contact-Flow** - Employee authentication with Lambda & DynamoDB
4. **Amazon-Lex-Enhanced** - Lex fulfillment Lambda & booking storage
5. **Send-Email-Confirmation** - SES email notifications
6. **custom-ccp (main)** - Serverless custom CCP with S3/CloudFront

## Overview

IAC components for Amazon Connect hotel booking call center
